# Source licences (paper-figure dataset)

One row per paper in `data/raw/papers/`. Copy the licence **verbatim** from the
article page / PDF (same text as `licence:` in that paper's `meta.yaml`).
"Redistribution allowed" = may the figure images themselves be shared outside
this project (e.g. in a released dataset)? If unsure, write `no` / `unknown`.
Figure images are never committed to git regardless.

| paper_id | doi | licence (verbatim) | redistribution allowed (yes/no/unknown) | checked by | checked on | notes |
|---|---|---|---|---|---|---|
| _example: gargalis2023met_ | _10.xxxx/yyyy_ | _CC BY 4.0_ | _yes (with attribution)_ | _name_ | _YYYY-MM-DD_ | |
